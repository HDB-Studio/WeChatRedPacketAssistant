# 雙步點擊 (TwoStepClicker)

一個基於 Android 無障礙服務（AccessibilityService）的**兩步順序點擊**工具。

## 重要聲明

本專案是一個**通用的自訂雙步點擊工具**，不是微信紅包外掛：

- 不抓包、不解析任何網路流量
- 不偵測、不辨識紅包
- 不在背景自動執行任何操作
- 只在使用者主動觸發（點通知按鈕）時，依序執行兩個由使用者自訂的點擊

微信的紅包功能有反自動化偵測，本工具在微信上不會生效，也不應被用於此用途。

## 功能

- 兩個依序執行的點擊動作，每步可選：
  - 文字（`findAccessibilityNodeInfosByText`）
  - contentDescription
  - viewId
  - 螢幕座標（百分比，與解析度無關）
- 每步可設定執行前的等待毫秒數
- 可指定目標 App 套件名稱，前景不符則拒絕執行
- 觸發方式：常駐通知的「執行」按鈕，或主畫面測試按鈕

## 使用

1. 安裝 APK
2. 開啟 App →「① 開啟無障礙服務設定」→ 找到「雙步點擊」並開啟
3. 設定兩個步驟 →「② 儲存設定」
4. 「③ 顯示執行通知」→ 切換到目標 App → 下拉通知欄點「執行」

## 建置

```bash
gradle assembleDebug
```

需求：JDK 17、Gradle 8.x、Android SDK Platform 34、Build-Tools 34.0.0。
